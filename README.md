# pg_whoisactive
**PostgreSQL live incident investigation tool for DBAs.**

`pg_whoisactive` is a lightweight terminal UI for PostgreSQL, inspired by SQL Server's `sp_WhoIsActive`.

Host CPU
PostgreSQL CPU
TPS
